# AMZUltimate-Calculator-TOOL

跨境电商成本、FBA、仓储、广告与利润测算工具。

在线地址： https://biblobi.github.io/LT-TOOL/

## 贡献者与修改细节

- AJAX（原作者）：创建并维护原始项目；实现单位换算、运费与仓储计算、广告费换算、利润测算、PDF 聚合、图片格式转换、汇率工具、美国站 FBA 费率、仓储预测、库存规划、补货建议及页面交互。
- am-tmac：基于原项目创建 amazon-tool fork；增加日本站 FBA 配送费、月度仓储费、商品类别和售价阶梯佣金、利润测算、保本售价、盈亏平衡计算、多站点币种联动，并修复日本站费用和利润计算问题。
- 艾因：在 LT-TOOL-低客单价运费修改版.html 中增加美国站标准件售价低于 9.90 美元时的低客单价 FBA 配送费阶梯、价格分段、费率配置、燃油附加费和费用展示逻辑。

## 当前合并版本

index.html 以原项目为基础，合并 am-tmac 的日本站等功能，并将艾因的低客单价规则直接加入 FBA 计算流程，不需要模式切换。美国标准件售价 < 9.90 美元使用低价费率；售价 >= 9.90 美元使用普通费率。

## 费率规则

Amazon 费率会按站点、类目、尺寸、重量、售价、库存和生效日期变化。欧洲站与英国站的完整自动费率需要按官方站点和商品类目逐级维护；当前不使用不完整费率表替代 Seller Central 实际费用。结果仅供估算，请以 Seller Central、Fee Preview 或 Revenue Calculator 为准。
